Method

How OPA-Pack works

Recognize object properties

OPA-Pack estimates properties from multiple views of each object, using examples of similar items to help infer attributes such as fragility and material. These properties identify pairs that should be kept apart.

Track what is already packed

The policy considers the shape of each candidate and where fragile or incompatible objects are already sitting in the bin.

Choose what to pack next

The learned policy selects an object and a placement that balance three goals: use space efficiently, separate incompatible items, and limit pressure on fragile ones.

Dataset

1,032 everyday objects

The OPA dataset contains 1,032 everyday objects from Objaverse-v1, grouped by use:

Each object retains its 3D geometry and class name and has 11 predicted properties:

  • 5 semantic labels: medicine, edible item, household chemical, ignition item, and flammable item.
  • 6 physical properties: softness, sharpness, inner material, outer material, fragility, and density level.

These labels also define which object pairs should be packed apart, such as sharp tools and soft fruit.
